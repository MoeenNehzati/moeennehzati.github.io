How to use
Double-click a node to hide it; double-click again in the Removed nodes list to restore it.
Toolbar (top-left, always visible): Highlight ancestors cycles focus (off → dim → hide); Delete node removes the selected node; Redraw all resets layout.
Hover a node or edge to preview metadata. Click to pin details here.
Click a type in the legend to hide or show that category. Causality is preserved via bridge edges.
h cycles ancestor focus (off → dim → hide). Esc or ✕ deselects. r redraws. c clears everything. f fits the graph.
Drag a node to reposition it. Drag the ⠿ handle on each section to reorder this panel.
Scroll to zoom in/out (centered at cursor). Drag empty space to pan. Use the toolbar +/−/Fit buttons or keyboard + − f.
Edge styles: solid = Verified; long-dashed = Likely; short-dashed = Speculative. Node borders: solid = explicit; dashed = model-introduced.
